# Frontend Design Guidelines
- Prioritize high-contrast, accessible, and semantic HTML architecture.
- Use fluid typography scales and spacing systems (multiples of 4px/8px).
- Avoid generic AI aesthetics (overused gradients, bland purple accents); aim for intentional, context-driven branding.
