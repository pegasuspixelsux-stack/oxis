# Impeccable Code & Execution Standards
- Zero tolerance for broken layouts, overlapping text on resize, or unhandled overflow states.
- Ensure every interactive element has explicit `:hover`, `:focus-visible`, and `:active` states.
- Validate responsive layouts meticulously across mobile, tablet, and desktop breakpoints.
